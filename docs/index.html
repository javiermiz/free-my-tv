How it works

No root. No cloud. Just your TV.

  1. 1

    Allow it once

    Turn on developer options and accept the "Allow USB debugging?" prompt on the TV. That's the only permission it needs.

  2. 2

    It swaps the home screen

    Through the TV's own ADB (localhost, nothing leaves the TV) it becomes the home screen and screensaver, and turns off the stock launcher plus a short list of promo apps. Nothing is uninstalled.

  3. 3

    Undo anytime

    One button brings back the factory home screen, screensaver and every app. If something ever goes wrong, it switches back by itself.

Install

About ten minutes, start to finish.

Free, open source and easy to undo.

  1. On the TV: Settings → System → About → press Android TV OS build 7 times. Back in System, open Developer options and turn on USB debugging. Write down the TV's IP address (Settings → Network & Internet).
  2. On your computer: get the code.
    git clone https://github.com/simbasjungles/free-my-tv && cd free-my-tv
  3. Open Claude Code in that folder and say:
    Install Free My TV on my TV at 192.168.1.50. I live in Lisbon.
    It installs the tools it needs, builds the app and puts it on your TV. Swap in your TV's IP and your city.
  4. Back on the TV: open Free My TV → Home Screen → Free My TV, and accept the debugging prompt (tick Always allow).
  1. On the TV: turn on Developer options and USB debugging (as in the other tab), and note its IP address.
  2. Tools: a JDK (17+), the Android SDK command-line tools and adb. On a Mac:
    brew install --cask temurin android-commandlinetools android-platform-tools && sdkmanager "build-tools;34.0.0" "platforms;android-34"
  3. Build: the first run creates config.properties. Add your city there and, for the trending picks, a free TMDB key. Then build again.
    git clone https://github.com/simbasjungles/free-my-tv && cd free-my-tv && ./build.sh
  4. Install:
    adb connect 192.168.1.50:5555 && adb install -r FreeMyTV.apk
  5. On the TV: open Free My TV → Home Screen → Free My TV.

FAQ

Good questions.

Is it safe?

It uses the same commands as Android's own developer tools, from inside the TV. Nothing is rooted or uninstalled: apps are only turned off and come back with one button. Picture, sound, inputs, the remote, Google services and the Play Store are on a never-touch list.

How do I go back?

Open Free My TV → Home Screen → Original. The factory home screen, screensaver and every app come back exactly as they were. If the new home screen ever crashes three times in five minutes, it switches back on its own.

Does it change picture quality?

No. Picture settings aren't touched, and videos play through the same hardware path. We measured the same resolution and the same video source in both modes.

What gets turned off?

The stock home screen and screensaver (replaced), Google TV's recovery home, Play Games and YouTube Music, and on TCL TVs the TCL Channel, messages, store demo, hotel menu, manuals, mirroring and logging apps. Google Assistant only if you ask for it in the config.

Can I make it mine?

That's the idea. Open the folder in Claude Code and just ask: "add Crunchyroll to the shelf", "show prices in euros", "set it up for my Sony". It changes the code, rebuilds the app and puts it on your TV.

Does it speak my language?

English and Portuguese, following the TV's language. Want another one? Ask Claude to add it.

Does it collect any data?

No accounts, no analytics, no tracking. It only talks to TMDB (picks), Open-Meteo (weather, with the coordinates you set) and Binance (prices).

Is it free?

Yes. MIT license, and the TMDB key is free too.
